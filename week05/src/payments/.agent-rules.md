# src/payments/ 규칙

- **금액 단위**: 모든 금액은 전(minor unit) 정수로 다룹니다. float/소수 금지.
- **로그**: 결제 관련 로그는 `lib/logger.js`의 `logPayment()`만 사용합니다. `console.log`, `log()` 직접 호출 금지.
- **테스트**: 이 폴더 코드를 변경한 뒤에는 반드시 `npm test`를 실행해 통과를 확인합니다.

자세한 규칙은 `@docs/payment-rules.md`, 절대 위반 금지 규칙은 `@GOLDEN_RULES.md` 참조.
