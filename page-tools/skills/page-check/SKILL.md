# 🔍 페이지 점검 스킬 (`page-check`)

> Claude Code 전용 로컬 스킬입니다 (Gemini와 공유하지 않음, `.agents/skills/`에 원본 없음).

**트리거:** `/page-check`, "페이지 점검", "page check"

HTML 페이지를 5가지 관점에서 점검하고, 발견된 문제를 심각도별로 분류하여 보고합니다.

---

## 📌 사용법

```text
/page-check [파일경로 또는 대상 설명]
```

**예시:**
- `/page-check`
- `/page-check index.html`
- `페이지 점검해줘`
- `page check hello.html`

파일경로가 명시되지 않으면 현재 작업 중이거나 최근에 수정된 HTML 파일을 우선 대상으로 삼고, 여러 개면 사용자에게 어떤 파일을 점검할지 확인합니다.

---

## 🧪 점검 항목 (5가지 관점)

### 1. title 유무
`<head>` 안에 `<title>` 태그가 존재하고, 내용이 비어있지 않은지 확인합니다.
- 없거나 비어있음 → 🔴 심각 (브라우저 탭·검색결과·즐겨찾기에 페이지를 식별할 방법이 없음)

### 2. 깨진 내부 링크
`<a href="...">`, `<img src="...">`, `<link href="...">`, `<script src="...">` 등에서 외부 URL(`http://`, `https://`, `//`)과 앵커(`#`)를 제외한 상대경로를 추출해, 실제로 해당 파일이 존재하는지 확인합니다.
- 대상 파일이 존재하지 않음 → 🔴 심각 (사용자가 클릭 시 404를 만남)

### 3. 이미지 alt
모든 `<img>` 태그에 `alt` 속성이 있는지 확인합니다.
- `alt` 속성 자체가 없음 → 🟡 주의 (스크린리더 접근성 문제, SEO 손해)
- `alt=""` (빈 값)만 있음 → 🟢 제안 (장식용 이미지면 의도적일 수 있으나, 의미 있는 이미지라면 대체 텍스트를 채우도록 제안)

### 4. 모바일 viewport
`<head>` 안에 `<meta name="viewport" content="width=device-width...">` 형태의 태그가 있는지 확인합니다.
- 없음 → 🟡 주의 (모바일에서 레이아웃이 깨지거나 확대되어 보일 수 있음)
- 있지만 `width=device-width`가 빠져있음 → 🟢 제안

### 5. 한글 인코딩 (UTF-8)
`<head>`의 가장 앞부분에 `<meta charset="UTF-8">` (또는 `<meta http-equiv="Content-Type" content="text/html; charset=utf-8">`)가 있는지 확인합니다.
- 인코딩 선언 자체가 없음 → 🔴 심각 (한글이 브라우저에서 깨져 보일 위험)
- UTF-8이 아닌 다른 인코딩(예: EUC-KR) → 🟡 주의 (의도적일 수도 있으나 대부분의 경우 UTF-8 권장)
- 선언은 있으나 `<head>` 앞쪽(가급적 첫 1024바이트 이내)에 위치하지 않음 → 🟢 제안

## ⚙️ 실행 절차 (Workflow)

### 1단계: 대상 파일 확정
1. 사용자가 지정한 파일 또는 현재 작업 중인 HTML 파일을 확인합니다.
2. 파일을 읽습니다.

### 2단계: 5가지 항목 점검
1. 위 점검 항목 1~5를 순서대로 검사합니다.
2. 내부 링크 검사 시에는 파일이 위치한 디렉터리를 기준으로 상대경로를 해석합니다.
3. 각 항목에서 발견된 문제를 심각도(🔴/🟡/🟢)와 함께 구체적인 위치(줄 번호, 태그, 속성값)로 기록합니다.

### 3단계: 결과 보고
아래 형식으로 심각도 그룹별로 묶어서 보고합니다. 문제가 없는 항목은 🟢 통과로 짧게 표시합니다.

```text
## 📋 페이지 점검 결과 — <파일명>

🔴 심각 (N건)
- [항목명] 구체적인 문제 설명 (위치)

🟡 주의 (N건)
- [항목명] 구체적인 문제 설명 (위치)

🟢 제안 / 통과
- [항목명] 문제 설명 또는 "이상 없음"
```

### 4단계: 다음 단계 안내
- 🔴 심각 항목이 있다면 즉시 수정할지 사용자에게 물어보고, 동의하면 수정 후 `/commit` 스킬로 이어지도록 안내합니다.
- 수정할 파일이 여러 개인 경우, 파일별로 위 보고 형식을 반복합니다.
